# Outils recherche d'emploi pour Claude

Marketplace de plugins Claude pour les cadres en recherche d'emploi.

| Plugin | Ce qu'il fait |
|---|---|
| **radar-candidatures** | Tableau de bord personnel : collecte des offres (LinkedIn, Apec, Indeed) à partir des alertes, classement A/B/C selon tes critères, suivi des candidatures, lettres de motivation et CV adaptés générés depuis ton CV et ton profil LinkedIn. |

## Installation

**Claude (Cowork, application de bureau ou claude.ai)**
1. Barre latérale : **Personnaliser** (Customize), puis **Plugins**.
2. **Ajouter une marketplace** (Add marketplace), colle : `sAbus133/outils-recherche-emploi`
3. Installe **radar-candidatures**.
4. Dans une nouvelle conversation, tape `/radar-installation` et laisse-toi guider.

**Claude Code**
```
/plugin install radar-candidatures --marketplace sAbus133/outils-recherche-emploi
```

## Mises à jour

Page Plugins, puis bouton **Mettre à jour** (Update) sur la marketplace. Ta page radar et tes données ne sont pas touchées.
